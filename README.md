# Poke∞

Juego de navegador inspirado en Vampire Survivors con temática Pokémon: sobrevive a las oleadas, entra en grietas para mejorar tus habilidades (nivel 1 a 5) y fusiónalas.

## Jugar en local
Abre `index.html` en el navegador, o sirve la carpeta:

```
python3 -m http.server 8000
```
